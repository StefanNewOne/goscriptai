# ingest/ — влез на информации за Мозокот (локална обработка)

Хибрид архитектура: тешката, фајл-врзана обработка (видео→сценарио, веб скрејп→каталог, графики→offers) се прави **локално** на машината каде живеат фајловите, и праќа само **структурирани предлози** во GoScriptAI backend, каде сценаристот ги потврдува. Мозокот и генерацијата остануваат онлајн.

## Статус
- [x] `gemini-video-to-script.md` — промпт + упатство за тестирање на видео→сценарио екстракцијата во Google AI Studio.
- [x] `script.schema.json` — JSON шема на екстракцискиот излез (`script` = вистина од видео, `brain` = предлози).
- [ ] Локална алатка (Node) што ги пушта видеата едно по едно и ги POST-ира предлозите — се гради **откако** промптот ќе даде квалитетен излез на 3–4 видеа.
- [ ] Веб скрејп + графики модули.

## Прв чекор (сега)
Тестирај го промптот на 3–4 видеа по 1–2 клиенти (види `gemini-video-to-script.md`), врати ги JSON излезите → рафинираме промптот/шемата пред да ја градиме алатката.
