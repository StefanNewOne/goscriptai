# ingest/ — влез на информации за Мозокот (локална обработка)

Хибрид архитектура: тешката, фајл-врзана обработка (видео→сценарио, веб скрејп, графики) се прави **локално** каде живеат фајловите, и подоцна праќа само **структурирани предлози** во GoScriptAI backend каде сценаристот ги потврдува. Мозокот и генерацијата остануваат онлајн.

## Видео → сценарио (готово за тест)

Скриптата `video-to-script.mjs` ја пушташ врз фолдер на клиент со видеа; за секое видео пишува `.json` (структура) + `.md` (читливо сценарио) во подфолдер **`сценариа`**.

### Еднократна подготовка
```bash
cd ingest
npm install                 # инсталира @google/genai
copy .env.example .env      # (на Windows). Внеси GEMINI_API_KEY
```
`GEMINI_API_KEY` го земаш од Google AI Studio. По потреба смени `GEMINI_MODEL` во `.env`.

### Пуштање врз фолдер на клиент
```bash
npm run video -- "C:\Users\User\Desktop\usb\ace\Desktop\Surovi videoa\ИМЕ-НА-КЛИЕНТ"
```
Резултат: `...\ИМЕ-НА-КЛИЕНТ\сценариа\<видео>.json` + `<видео>.md`.

### Праќање во системот (`--push`)
За да влезат резултатите директно во Мозокот на клиентот (како PENDING, за потврда):
```bash
npm run video -- "C:\...\Surovi videoa\GoDigital" --push --client=GODIGITAL
```
Клиентот се бара по **код** (`--client=КОД`) — прво креирај го клиентот во UI. Бара `API_URL` + `INGEST_EMAIL`/`INGEST_PASSWORD` во `.env`. Без `--push` алатката само пишува локални фајлови.

- Идемпотентно: прескокнува видео што веќе има `.json`.
- Пад на едно видео не го запира останатото.
- Прво тестирај на **3–4 видеа** (стави ги во мал тест-фолдер) → прати ми ги `.md`/`.json` → рафинираме `prompt.txt` пред да пуштиш сè.

### Рафинирање
Промптот е во **`prompt.txt`** (без код). Го менуваме таму додека излезот не биде одличен.

## Фајлови
- `video-to-script.mjs` — алатката.
- `prompt.txt` — инструкцијата за Gemini (уредлива).
- `script.schema.json` — референтна JSON шема на излезот.
- `gemini-video-to-script.md` — документација + пример + рачно тестирање во AI Studio.
- `.env.example` — GEMINI_API_KEY, GEMINI_MODEL.

## Следно (по валидација на 3–4 видеа)
- Скалирање на сите видеа по клиент.
- POST на предлозите во GoScriptAI backend (Мозок, PENDING).
- Веб скрејп + графики модули.
